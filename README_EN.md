# 2022Autumn-BUAA-CO

## Course Project for BUAA Computer Organization (Autumn 2022)

![Hand-drawn P5 pipeline diagram](https://github.com/user-attachments/assets/3704f753-66ad-4cce-a720-730e76948d19)

Special thanks to JKM for providing the hand-drawn P5 pipeline sketch.

## Repository Contents

- `P0~P2`: selected foundational exercises.
- `P3~P8`: complete source code and design reports.

> The final P8 implementation is a five-stage pipelined CPU with multi-peripheral interaction and exception handling, supporting 30+ MIPS instructions.

## Notes

This repository was created quite a while ago, when the author had just started in the CS program. At that time, documentation practices (especially Markdown writing and continuous design-note tracking) were still immature.

So while the codebase can still be useful for reference, some non-code content may be rough around the edges. Please use it critically and take what is helpful.

Feedback and discussions are welcome.
